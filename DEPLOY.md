# Деплой bitva-ekstrasensov-help.com

При просьбе пользователя задеплоить сайт выполняй весь порядок ниже. Это согласованный процесс обновления кода и полного пересоздания production-базы из локального дампа.

## Подготовка

Рабочая папка: `D:\bitva\bitva-ekstrasensov-help`.

1. Прочитай `AGENTS.md`, проверь изменения и ветку `main`.
2. Обнови полный дамп: `npm --prefix backend run db:dump`.
3. Пересобери фронтенд: `npm --prefix frontend run build`. Скрипт полностью очищает `backend/build`.
4. Проверь отсутствие служебных строк `/*!... */` и `/*M!... */` в дампе и сохранность исходных записей `admin_users`.
5. Выполни подходящие проверки и `git diff --check`. При ошибке останови деплой и исправь причину.
6. Закоммить изменения задачи, свежий `backend/dump.sql` и всю сборку, включая удаления. Выполни `git push origin main`, не обходя hook.
7. Убедись, что рабочая папка чистая и `main` синхронизирована с `origin/main`.

## Кабинет и Plesk

1. Открой https://hoster.kz/cabinet/ в видимом браузере.
2. Если требуется вход, попроси пользователя самостоятельно ввести логин и пароль на сайте и сообщить о завершении. Не проси присылать пароль в чат.
3. Перейди на https://hoster.kz/cabinet/all-services/?hosting=yes&vps=yes.
4. Выбери **Хостинг bitva-ekstrasensov-help.com**: https://hoster.kz/cabinet/hosting/147749/.
5. Нажми **Войти в панель** и дождись новой вкладки Plesk. Проверенная панель — `https://pkz42.hoster.kz:8443`.

## Получение кода

1. На странице **Сайты и домены** открой **Git** нужного сайта.
2. Проверь репозиторий `https://github.com/Veterok-Iz-Popki/bitva-ekstrasensov-help.git` и ветку `main`.
3. Нажми **Получить сейчас** один раз и дождись завершения.
4. Проверь соответствие последнего коммита отправленному. Настроено автоматическое развертывание `main` в `/httpdocs`; отдельную кнопку **Развернуть сейчас** в проверенном процессе не нажимали.

## Импорт базы

1. Вернись в **Сайты и домены**, открой **Базы данных** нужного сайта.
2. Нажми **Импортировать дамп** для базы `p-356716_bitva-ekstrasensov-help`.
3. Выбери загрузку с локального компьютера и нажми **Выбрать файл...**.
4. Выбери `D:\bitva\bitva-ekstrasensov-help\backend\dump.sql` — свежий файл, отправленный в Git на этапе подготовки.
5. Оставь включённым **Заново создать базу данных**: production-база полностью заменяется локальным дампом.
6. Нажми **Импортировать дамп** один раз и дождись окончания.
7. Проверь новое сообщение **«Дамп базы данных p-356716_bitva-ekstrasensov-help импортирован»** после этой операции. Старое уведомление не подтверждает новый импорт. При ошибке остановись.

## Перезапуск и проверка

1. Вернись в **Сайты и домены** и открой **Node.js**.
2. Нажми **Перезапустить приложение** и дождись подтверждения.
3. Если Plesk сообщает **«Приложение будет перезапущено по первому запросу»**, открой https://bitva-ekstrasensov-help.com/ и проверь загрузку сайта.
4. Проверь изменённый контент на production; для описания фотографии открой фотогалерею и нужное фото.
5. Сообщи пользователю результат и задеплоенный коммит. При ошибке укажи незавершённый шаг.

Другие настройки хостинга не меняй. Не сохраняй пароли кабинета, базы и SMTP в Git, документах, отчётах или скриншотах результата. Используй актуальные элементы интерфейса; при изменении интерфейса сначала прочитай его состояние.
