# Работа с проектом

- GitHub Actions не собирает и не коммитит фронтенд. Production-сборка хранится в `backend/build`.
- Перед каждым push запускай `npm --prefix frontend run build`. Скрипт полностью очищает `backend/build`, собирает фронтенд и выполняет постобработку HTML.
- При ошибке сборки не отправляй изменения. После успешной сборки добавь все изменения, включая удаления, через `git add -A -- backend/build` и включи их в коммит вместе с изменениями исходников.
- Проверь `git diff --check` и состояние репозитория перед коммитом.
- В каждом новом checkout включай проверку перед push: `git config core.hooksPath .githooks`. Не обходи pre-push hook.
- Production-параметры задаются в `frontend/.env.production.local` или переменных окружения. Не коммить локальные env-файлы.
