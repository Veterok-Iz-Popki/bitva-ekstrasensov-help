# PRD — Битва Экстрасенсов — Официальный сайт помощи

## Оригинальная постановка
SEO-оптимизированный сайт сбора заявок на помощь экстрасенсов с CMS-управлением всего контента из административной панели.

## Архитектура
- **Backend:** Node.js Express + MariaDB (mysql2) + JWT (jsonwebtoken) + bcryptjs
- **Frontend:** React 18 + Tailwind CSS + shadcn/ui + react-router-dom
- **Email:** Resend (Node SDK)
- **Images:** Sharp (Node.js)
- **Database:** MariaDB 10.11

## Миграция (Март 2026)
Бэкенд полностью переписан с Python FastAPI + MongoDB на Node.js Express + MariaDB.
- Все 30+ API-эндпоинтов сохранены с теми же URL и форматами ответов
- Frontend не изменялся
- 100% тестов пройдено (25/25 backend + all frontend)

## Реализовано

### CMS и Админ-панель
- JWT-аутентификация
- CRUD: участники, отзывы, FAQ, страницы, SEO-настройки, настройки сайта
- Фотогалерея и Видеогалерея
- Экспорт заявок в CSV
- Email-уведомления (Resend)

### Публичный сайт
- Главная: Герой, Участники, Отзывы (карусель), CTA, Услуги, SEO-текст
- **Личные страницы экстрасенсов** — унифицированный шаблон по образцу референса (Март 2026):
  - Двухколоночный layout (фото+отзывы / статус+специализация+услуги+CTA+описание)
  - Автоматическое склонение имён (родительный, дательный, творительный падежи)
  - Модальная форма заявки по кнопке «Обратиться»
  - Блоки услуг (Помощь, Консультация, Запись на приём)
  - CTA-блок с призывом к действию
  - Инструкции получения помощи
  - Адаптивная верстка (десктоп/мобильный)
  - Все 8 страниц проверены (22/22 тестов)
- 6 тематических страниц + 4 страницы услуг
- Фотогалерея, Видеогалерея
- Форма записи (honeypot + маска телефона)
- FAQ

### UI/UX
- Шапка: fixed desktop/tablet, static mobile
- Якорные ссылки: Экстрасенсы, Отзывы, Услуги
- ScrollToTop, scroll-margin-top
- Уникальные CTA-кнопки на тематических страницах
