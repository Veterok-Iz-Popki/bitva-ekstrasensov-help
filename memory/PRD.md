# PRD — Битва экстрасенсов: Официальный сайт помощи

## Проблема
SEO-оптимизированный русскоязычный сайт для привлечения заявок от людей, ищущих помощь экстрасенсов.

## Архитектура
- **Frontend:** React + Tailwind CSS + Shadcn UI
- **Backend:** FastAPI + MongoDB (Motor async driver)
- **Auth:** JWT (admin panel)
- **Spam protection:** Honeypot + Rate limiting
- **Email:** Resend (опционально, требует API key)

## Пользователи
- **Посетители** (25-65 лет, преимущественно женщины) — ищут помощь экстрасенсов
- **Администратор** — управляет всем контентом через CMS

## Реализовано (24.02.2026)

### Публичные страницы
- Главная (/) — hero, о проекте, услуги, преимущества, форма, SEO-текст
- Участники (/uchastniki) — карточки экстрасенсов, bento grid
- Профиль участника (/uchastniki/:slug) — полная информация, кнопка записи
- Запись на приём (/zapis-na-priem) — форма + процесс консультации
- Отзывы (/otzyvy) — отзывы + блок доверия
- FAQ (/voprosy-i-otvety) — аккордеон вопросов-ответов
- Контакты (/kontakty) — форма обратной связи + контактная информация

### CMS Админ-панель (/admin)
- JWT авторизация (admin/admin123)
- Dashboard со статистикой
- CRUD: Участники, Отзывы, FAQ
- Редактирование контента страниц
- Управление SEO мета-тегами по страницам
- Просмотр/управление заявками (статусы, заметки)
- Просмотр сообщений обратной связи
- Настройки сайта (email, часы работы, копирайт)

### SEO
- Уникальные Title/Description для каждой страницы
- Ключевые слова для Яндекса
- Schema.org JSON-LD микроразметка
- ЧПУ URL с транслитерацией
- Правильная структура H1-H3

### Дизайн
- Тёмная мистическая стилистика (#050505 / #6b1525 / #d4af37)
- Шрифты: Cormorant Garamond (заголовки) + Manrope (текст)
- Адаптивный (desktop / tablet / mobile)
- Glassmorphism, noise overlay, gold glow effects

## Бэклог
- P0: Настройка Resend API key для email-уведомлений
- P1: Загрузка собственных фото участников через админку (file upload)
- P1: Смена пароля администратора из CMS
- P2: Экспорт заявок в CSV/Excel
- P2: Фильтрация заявок по статусу/дате
- P2: WYSIWYG редактор для текстового контента
- P3: Мультиязычность (если нужна)
