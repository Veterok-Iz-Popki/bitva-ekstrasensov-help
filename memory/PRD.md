# PRD — Битва Экстрасенсов — Официальный сайт помощи

## Оригинальная постановка
SEO-оптимизированный сайт сбора заявок на помощь экстрасенсов с CMS-управлением всего контента из административной панели.

## Архитектура
- **Backend:** FastAPI + MongoDB (Motor) + Pydantic + JWT
- **Frontend:** React + Tailwind CSS + shadcn/ui + react-router-dom
- **Email:** Resend
- **Images:** Pillow

## Реализовано

### CMS и Админ-панель
- JWT-аутентификация
- CRUD: участники, отзывы (привязаны к экстрасенсу), FAQ, страницы (тематические, услуги), SEO-настройки, настройки сайта
- Фотогалерея и Видеогалерея (загрузка/удаление через CMS)
- Экспорт заявок в CSV
- Email-уведомления о новых заявках (Resend)

### Публичный сайт
- Главная страница с блоками: Герой, Участники, Преимущества, **Отзывы (карусель)**, Услуги, SEO-текст
- Личные страницы экстрасенсов с отзывами
- 6 тематических страниц (Порча, Проклятие, Сглаз и т.д.)
- 4 страницы услуг (Финансовая магия и т.д.)
- Фотогалерея, Видеогалерея
- Форма записи на приём (honeypot-защита)
- FAQ

### UI/UX
- Шапка: fixed на desktop/tablet (>=768px), static на mobile (<768px)
- Мобильное меню без бургера — все пункты видны
- Якорные ссылки: Экстрасенсы, Отзывы, Услуги
- ScrollToTop при навигации
- scroll-margin-top для якорных секций

### Блок «Отзывы» на главной (Февраль 2026)
- Карусель агрегированных отзывов со всех экстрасенсов
- API: `/api/reviews?limit=30` — обогащение `participant_name`, случайная перемешка
- Стрелки, точки-индикаторы (smart pagination для >15), счётчик
- Звёзды рейтинга, текст, автор+город, ссылка на экстрасенса
- Якорь `id="otzyvy"`, пункт меню «Отзывы» → `/#otzyvy`
- Отдельная страница `/otzyvy` удалена
