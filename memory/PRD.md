# PRD — Битва Экстрасенсов — Официальный сайт помощи

## Оригинальная постановка
SEO-оптимизированный сайт сбора заявок на помощь экстрасенсов с CMS-управлением всего контента из административной панели.

## Архитектура
- **Backend:** Node.js Express + MariaDB (mysql2) + JWT (jsonwebtoken) + bcryptjs
- **Frontend:** React 18 + Tailwind CSS + shadcn/ui + react-router-dom
- **Email:** Resend (Node SDK)
- **Images:** Sharp (Node.js)
- **Database:** MariaDB 10.11

## Миграция (Март 2026)
Бэкенд полностью переписан с Python FastAPI + MongoDB на Node.js Express + MariaDB.
- Все 30+ API-эндпоинтов сохранены с теми же URL и форматами ответов
- Frontend не изменялся
- 100% тестов пройдено (25/25 backend + all frontend)

## Реализовано

### CMS и Админ-панель
- JWT-аутентификация
